🎯 Features

1. Import/Export

  • Chrome Import — Import bookmarks from Chrome HTML export
  • JSON Export — Full data export (bookmarks, categories, tags, history)
  • Chrome HTML Export — Export with categories as folders
  • Import New Only — Skip duplicate bookmarks during import

2. AI Categorization

  • DeepSeek API — Uses deepseek-v4-flash model
  • Keyword Matching — Fast pre-matching with extensive keyword lists
  • Batch Processing — Processes bookmarks in batches of 25
  • Progress Tracking — Real-time progress bar with ETA
  • Partial Results — Shows categories as they're classified
  • To Review — Bookmarks that couldn't be classified go here
  • Anomalies — Special category for chrome://, blob:, etc. URLs

3. Categories (18 total)

  • Career
  • Cooking/Food
  • DIY/Crafts
  • Education
  • Finance
  • Gaming
  • Health & Fitness
  • News
  • Productivity

  • Shopping
  • Social Media + Entertainment
  • Sports
  • Technology
  • Travel
  • Business
  • Science
  • To Review

4. Bulk Selection & Actions

  • Checkbox Selection
  • Select All
  • Bulk Archive
  • Bulk Unarchive
  • Bulk Delete
  • Move To
  • Selection Counter
  • Clear Selection

5. Link Checker

  • Link Status Badges — ✅ Verified, ❌ Broken, ⚠️ Redirect, ⏱️ Timeout, ❓ Error
  • Progress Modal — Real-time progress during scanning
  • Results Modal — Summary with broken links list
  • Bulk Actions — Move Broken to "To Review", Archive Broken, Delete Broken
  • Re-check Broken — Re-scan only broken links
  • Status Filter — Filter bookmarks by link status

6. Domain & URL Grouping

  • Domain Groups — Purple badge with domain name and count
  • URL Groups — Blue badge for exact URL duplicates
  • Stacked Cards — Visual stacking with fan-out effect
  • Popup — Click badge to see all grouped bookmarks
  • Expand View — Full-screen view of all bookmarks in a group

7. Archive Management

  • Archived Category — 🗄️ Archived in sidebar showing all archived bookmarks
  • Archived Badge — "📁 Archived" badge on archived cards (right side)
  • Show Archived Toggle — Toggle visibility of archived bookmarks
  • Bulk Unarchive — Select and unarchive multiple bookmarks
  • Individual Unarchive — Unarchive individual bookmarks with 📤 button

8. Alphabetical Navigation

  • A-Z Filter
  • # Filter for non-letter domains
  • Active Letter indicator
  • Letter Status (bold = has bookmarks, faded = no bookmarks)

9. Search

  • Wildcard Support — * (any characters) and ? (single character)
  • Search Fields — Title, URL, description, folder path, category, tags
  • Real-time — Updates as you type

10. Sorting

  • Date Added (Newest)
  • Date Added (Oldest)
  • Title
  • URL
  • Category

🔒 Security

  • All data stored in browser localStorage
  • API key stored in memory only (prompted on load)
  • No data sent to external servers (except DeepSeek API)
  • XSS protection via sanitization
  • No tracking or analytics
