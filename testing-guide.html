🧪 Full Testing Guide

Step 1: Clear All Data

Option A: From the App

  1. Click "🗑️ Clear All" button in the header
  2. Confirm the dialog
  3. All bookmarks, categories, and history are cleared

Option B: From Browser Console (F12)

// Clear everything
app.bookmarkManager.clearAll();
app.categoryManager.setCategories(['All']);
app.importManager.clearImportHistory();
app.saveData();
app.renderAll();
console.log('✅ All data cleared');
location.reload(); // Optional: reload to reset state

Option C: Clear Browser Data

  1. Open Dev Tools (F12)
  2. Go to Application tab
  3. Storage → Local Storage
  4. Right-click on your domain → Clear
✅ After clearing: You should see "All" category only, "0 bookmarks" in the header, empty grid with import button, and no progress bar visible.

Step 2: Refresh the Page

Refresh the page. You should see:

  • ✅ "All" category only
  • ✅ "0 bookmarks" in the header
  • ✅ Empty grid with import button
  • ✅ No progress bar visible

Step 3: Import Bookmarks

  1. Export from Chrome: Go to chrome://bookmarks/ → Click the three dots → "Export bookmarks"
  2. Click "📥 Import" in the app
  3. Check "Import new bookmarks only" (should be checked by default)
  4. Select your HTML file
  5. Wait for import — you should see: 
    Successfully imported X new bookmarks from "file.html"!
  6. Check the sidebar — "All" should show the total count
💡 Tip: If you have 2022 bookmarks, the import should show exactly that number.

Step 4: Run AI Classification

  1. Click "🤖 Auto-Classify"
  2. Enter your DeepSeek API key when prompted
  3. Progress bar appears showing:
    • Total bookmarks
    • Classified count
    • ETA
    • Batch progress
  4. Wait for completion (5-20 minutes depending on bookmarks)
  5. Progress bar auto-hides when complete
  6. Categories appear in the sidebar with counts
⚠️ Note: If you don't have a DeepSeek API key, you can still test all other features except AI classification.

Step 5: Test Link Checker

  1. Click "🔗 Check Links"
  2. Confirm the dialog
  3. Progress modal appears showing:
    • Progress bar
    • Working/Broken/Redirect counts
  4. Wait for completion (2-5 minutes for 2000 bookmarks)
  5. Results modal shows:
    • Summary cards with counts
    • Broken links list (if any)
    • Action buttons
  6. Check cards — Link status badges appear (✅ Verified, ❌ Broken, etc.)
💡 Tip: The link checker uses no-cors mode, so it may not detect all broken links perfectly. It's a best-effort check.

Step 6: Test Categories & Navigation

  1. Click different categories in the sidebar
  2. Check header count matches the category count
  3. Click "🗄️ Archived" (should show 0 if none archived)
  4. Click "📁 Show Active" to return

Step 7: Test Bulk Selection

  1. Hover over a card → Checkbox appears in top-left
  2. Select 2-3 bookmarks by checking boxes
  3. Action bar appears with:
    • "X selected" count
    • 📥 Archive button
    • 📤 Unarchive button
    • 🗑️ Delete button
    • 📂 Move To button
  4. Click "📂 Move To" → Modal opens with categories
  5. Select a category → Bookmark moves to that category
  6. Check sidebar — category counts update

Step 8: Test Archive

  1. Select a bookmark → Click "📥 Archive"
  2. Confirm the dialog
  3. Check sidebar — "🗄️ Archived" appears with count (if first archive)
  4. Click "🗄️ Archived" to see archived bookmarks
  5. Archived cards show:
    • "📁 Archived" badge on right side
    • "📁 Archived (was: [category])" in footer
    • 📤 (Unarchive) button
  6. Select archived items → "📤 Unarchive" button appears
  7. Click "📤 Unarchive" → Bookmarks restored to original category

Step 9: Test Alphabet Navigation

  1. Click a letter in the right-side alphabet nav (e.g., "M")
  2. Only bookmarks starting with that letter show
  3. Header shows "All Bookmarks • Letter: M"
  4. Letter is highlighted in the nav
  5. Click the letter again to clear filter

Step 10: Test Search

  1. Type a search term in the search bar (e.g., "github")
  2. Results filter in real-time
  3. Wildcards work: *reddit*, techn?logy
  4. Search clears selection and letter filters
  5. Press Escape to clear search

Step 11: Test Sorting

  1. Click "Sort by" dropdown
  2. Try each option:
    • Date Added (Newest) → Newest first
    • Date Added (Oldest) → Oldest first
    • Title → Alphabetical by title
    • URL → Alphabetical by URL
    • Category → Alphabetical by category

Step 12: Test Expand View (Domain/URL Groups)

  1. Find a card with a purple badge (domain group)
  2. Click the purple badge → Popup appears
  3. Click "🔍 Expand" → Full-screen view of all bookmarks in group
  4. Click "← Back" to return
  5. Click a card in expand view → Opens URL in new tab

Step 13: Test Export

  1. Click "💾 Export"
  2. Select format:
    • JSON → Full app data
    • Chrome HTML → Categories as folders
  3. Download the file
  4. Verify the exported file contains your bookmarks

Step 14: Import JSON Backup

  1. Clear all data (optional)
  2. Click "📥 Import"
  3. Select "Import from JSON Export"
  4. Choose your exported JSON file
  5. Verify all bookmarks and categories are restored

console.log('AI available:', !!app.aiClassifier);

// Check classification manager
console.log('Classification running:', app.classificationManager?.isRunning);

// Reset classification state
app.classificationManager.isRunning = false;
app.classificationManager.isPaused = false;
app.classificationManager.isCancelled = false;
app.resetUI();

// Check link checker state
console.log('Link checker running:', app.linkChecker.isRunning);

// Reset link checker
app.linkChecker.isRunning = false;
app.linkChecker.cancelled = false;

// Check bulk actions
console.log('BulkActions:', app.bulkActions);
console.log('Selected IDs:', app.bulkActions.getSelectedIds());

// Force sync selection
app.bulkActions.syncSelection();
