📚 Bookmark Manager

A web-based bookmark manager with AI-powered categorization using DeepSeek API.

Features

  • Import Chrome Bookmarks — Upload HTML export files
  • AI-Powered Categorization — Automatically sorts bookmarks using DeepSeek API
  • Smart Grouping — Groups bookmarks by domain and URL duplicates
  • Alphabetical Navigation — Quick access by domain letter
  • Search — Supports wildcard characters (* and ?)
  • Archive & Delete — Manage your bookmarks
  • Export — Export to Chrome HTML with categories
  • Bulk Operations — Select, archive, unarchive, delete, and move multiple bookmarks
  • Link Checking — Scan bookmarks for broken links with status badges
  • Stacked Card View — Visual grouping of domain and URL duplicates
  • Dark/Light Mode — Follows system preference

Tech Stack

  • Vanilla JavaScript (ES Modules)
  • CSS3 with responsive design
  • DeepSeek API for AI classification
  • localStorage for data persistence

Data Flow

Import Flow

User imports Chrome HTML → bookmarkParser.js parses the file → importManager.js adds bookmarks → storageManager.js saves to localStorage → UI updates

Classification Flow

User clicks "Auto-Classify" → aiClassifier.js gets categories from DeepSeek → classificationManager.js processes in batches → Each bookmark gets a category and tags → UI updates with progress → Completion state saved

View Flow

User views bookmarks → app.js renders categories and bookmarks → bookmarkManager.js groups by domain/URL → uiRenderer.js creates cards → stackRenderer.js creates stacked cards for groups

Link Check Flow

User clicks "Check Links" → linkChecker.js scans each URL → Progress updates in real-time → Results displayed with status badges → Bulk actions available for broken links

Group Interaction Flow

User clicks a badge (purple/blue) → popupManager.js shows popup with all bookmarks in group → User clicks "Expand" → expandView.js shows full-screen view of all bookmarks

Key Concepts

Categories

Bookmarks are organized into categories (e.g., Technology, Career, Gaming). Categories are determined by AI or manually assigned. "To Review" and "Anomalies" are special categories that always appear in the sidebar.

Groups

  • URL Groups (Blue badge): Exact duplicate URLs stacked together
  • Domain Groups (Purple badge): Different URLs from the same domain stacked together

Badges

BadgeColorLocation
📁 ArchivedGrayRight side of archived cards
✅ VerifiedGreenRight side of card
❌ BrokenRedRight side of card
⚠️ RedirectYellowRight side of card
⏱️ TimeoutOrangeRight side of card
❓ ErrorGrayRight side of card
🏢 DomainPurpleTop-right of stacked cards
📦 DuplicateBlueTop-right of stacked cards
⭐ NewestGreenOn date label

Sorting

  • Date Added (Newest/Oldest)
  • Title
  • URL
  • Category

Search

  • Supports wildcards: * (any characters) and ? (single character)
  • Searches: title, URL, description, folder path, category, tags
  • Real-time filtering as you type

Configuration

DeepSeek API

The app uses DeepSeek API for AI classification. You'll be prompted for your API key on first load. The key is stored in memory only and not persisted.

Thumbnails

Thumbnails use Google's free favicon API and are cached in localStorage for performance.

Stack Styles

Two stack styles available:

  • Fan: Cards fan out to the right (default)
  • Subtle: Minimal fan effect

To change: In js/ui/stackRenderer.js, modify this.stackStyle.
